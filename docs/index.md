# MühendisAl — teknik kesit

Bu, MühendisAl öğrenme platformunun mevcut arayüz ve API kodundan seçilmiş bir adaydır. Dersler ve 158 çeviri/referans içeriği burada yoktur. [Dashboard](dashboard.md) kaynak uygulamadan uyarlanmıştır; ders listesi bilinçli olarak çıkarılmıştır.

Bu kesit AjanMühendis adıyla planlanan görev/kanıt/portföy stüdyosu değildir. API çalıştırılırsa tarayıcı cihaz kimliği oluşturur ve yerel veritabanına kayıt yapar. Ayrıntı ve güvenlik sınırları için README'ye bakın.
